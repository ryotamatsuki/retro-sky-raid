# Retro Sky Raid

レトロアーケード風の全3ステージ縦スクロール・ピクセルシューティングゲームです。  
`retro_vertical_shooter_requirements.md` の初期実装スコープに沿って、HTML5 Canvas / JavaScript で作成しています。

## 起動方法

このゲームは `assets` 内のPNGをCanvas上で読み込み・切り抜き加工して使うため、ローカルサーバー経由で起動してください。

### 1. このフォルダに移動

```powershell
cd C:\Users\Owner\Desktop\workspace_new\proj_y_game\retro_vertical_shooter
```

### 2. サーバーを起動

```powershell
node serve.js
```

起動すると、標準では次のURLで開けます。

```text
http://127.0.0.1:4173/
```

別のポートを使いたい場合は、ポート番号を指定できます。

```powershell
node serve.js 4174
```

その場合は次のURLを開きます。

```text
http://127.0.0.1:4174/
```

`serve.js` は `127.0.0.1` で待ち受けるため、上記URLは起動したPC自身から開くURLです。スマホ実機から同一LAN経由で確認する場合は、別途外部アクセス可能なサーバー設定が必要です。

## 操作方法

| 操作 | キー |
|---|---|
| 決定 / ゲーム開始 | `Space` / `Enter` |
| 難易度選択 | `←` `→` / `↑` `↓` / `WASD` |
| 移動 | 矢印キー / `WASD` |
| ショット | `Space` / `Z` |
| ボム | `X` |
| ポーズ / 再開 | `P` / `Enter` |
| ミュート切り替え | `M` |
| タイトルへ戻る | `Esc` |
| ステージクリア後に次ステージへ | `Space` / `Enter` |
| ゲームオーバー後リトライ | `Space` |
| ゲームオーバー後タイトルへ戻る | `Enter` |

PCのマウスでは、ゲーム中にCanvas上のポインタ位置へ自機が移動し、押している間はショットを発射します。
PCのキーボード・マウス操作は従来どおりです。

### スマホ（portrait）

- タイトル画面のCanvasをタップして難易度選択へ進み、`EASY` / `NORMAL` / `HARD` の項目をタップすると、その難易度で開始します。
- ゲーム中は画面左側に固定表示されるアナログスティックで自機を移動します。相対ドラッグによる移動とAUTO FIREはありません。
- 画面右側の `FIRE` を押している間だけショットを発射します。移動中でも `MOVE` と `FIRE` を別々の指で同時に操作できます。
- `BOMB` は `FIRE` の近くに配置されています。ボム残数はボタンに表示され、0個では無効化されます。
- `PAUSE` / `MUTE` は画面右上に配置されています。ポーズ中は `RESUME`、ミュート中は `SOUND` に表示が変わります。

## スマホ検証チェック項目

- [ ] portrait表示でCanvas、左固定アナログスティック、右側の `FIRE`、近くの `BOMB`、右上の `PAUSE` / `MUTE` が表示される
- [ ] タイトル画面のCanvasタップで難易度選択へ進み、難易度タップでゲームが始まる
- [ ] 左固定アナログスティックの操作で自機が移動し、相対ドラッグでは移動しない
- [ ] `FIRE` を押している間だけショットが発射され、離すと停止する。title / difficulty / paused / stageclear / gameover / clearでは発射しない
- [ ] `MOVE` と `FIRE` を別々の指で同時に操作できる（マルチタッチ）
- [ ] portrait / landscape回転後もCanvas・操作ボタンがviewport内に収まり、safe-areaを侵食しない
- [ ] アナログスティック操作中に別指で `FIRE` や `BOMB` を押しても、移動用Pointerが解除されない
- [ ] `BOMB` は残数表示と0個時の無効化が機能する
- [ ] `PAUSE` / `RESUME` で停止・再開でき、`MUTE` / `SOUND` で音のON/OFFを切り替えられる
- [ ] PCでは矢印キー / `WASD`（移動）、`Space` / `Z`（ショット）、`X`（ボム）、`P` / `Enter`（ポーズ）、`M`（ミュート）が動作する

## ゲーム内容

- 画面下部の自機を操作して、上から来る敵機や地上兵器を撃破します。
- 敵弾や敵本体に当たるとミスになり、残機が減ります。
- 残機が0になるとゲームオーバーです。
- `P` アイテムを取るとショットが強化されます。
- `BOMB` アイテムを取るとボム回数が増えます。
- 全3ステージ構成で、各ステージ終盤にボスが出現します。
- ステージ1・2のボスを撃破するとステージクリア画面になり、`Space` / `Enter` で次ステージへ進みます。
- ステージ3のボスを撃破するとオールクリアです。
- ハイスコアはブラウザの `localStorage` に保存されます。

## ステージ構成

| ステージ | 名前 | 特徴 |
|---|---|---|
| 1 | `COASTAL BASE` | 海岸沿いの基地。基本的な敵編隊と地上兵器が中心です。 |
| 2 | `FOREST FORTRESS` | 森林要塞。砲台や中型機が増え、敵の耐久と弾幕が上がります。 |
| 3 | `FINAL RUNWAY` | 最終滑走路。敵密度、地上兵器、ボス弾幕がもっとも激しくなります。 |

## 難易度

タイトル画面から開始すると、難易度選択画面に移ります。

- `EASY`: 敵弾が遅めでアイテムが出やすい
- `NORMAL`: 標準バランス
- `HARD`: 敵弾が速く、敵の耐久と出現数が増える

## サウンド

- BGMと効果音はWeb Audio APIでリアルタイム合成しています。
- ステージごとに異なるチップチューン風BGMが流れます。
- ボス出現時はボス専用BGMへ切り替わります。
- ショット、敵弾、爆発、ボム、アイテム取得、被弾、ステージクリア、ゲームオーバーに専用効果音があります。
- ブラウザの仕様上、音はゲーム開始などのユーザー操作後に鳴り始めます。
- 音を止めたい場合は `M` キーでミュートを切り替えられます。

## サーバーの停止

起動中のターミナルで `Ctrl + C` を押すと停止できます。

別ウィンドウで起動してプロセスIDが分かっている場合は、PowerShellで停止できます。

```powershell
Stop-Process -Id <PID>
```

## トラブルシューティング

- 画面が真っ黒、または素材が読み込まれない場合は、`index.html` を直接開かず `node serve.js` で起動してください。
- `node` コマンドが見つからない場合は、Node.js をインストールしてください。
- `4173` ポートが使用中の場合は、`node serve.js 4174` のように別ポートを指定してください。
- 音が鳴らない場合は、一度ゲーム画面をクリックしてから `Space` / `Enter` で開始してください。
