# Retro Sky Raid

レトロアーケード風の全3ステージ縦スクロール・ピクセルシューティングゲームです。  
`retro_vertical_shooter_requirements.md` の初期実装スコープに沿って、HTML5 Canvas / JavaScript で作成しています。

## 起動方法

このゲームは `assets` 内のPNGをCanvas上で読み込み・切り抜き加工して使うため、ローカルサーバー経由で起動してください。

### 1. このフォルダに移動

```powershell
cd C:\Users\Owner\Desktop\workspace_new\proj_y_game\retro_vertical_shooter
```

### 2. サーバーを起動

```powershell
node serve.js
```

起動すると、標準では次のURLで開けます。

```text
http://127.0.0.1:4173/
```

別のポートを使いたい場合は、ポート番号を指定できます。

```powershell
node serve.js 4174
```

その場合は次のURLを開きます。

```text
http://127.0.0.1:4174/
```

## 操作方法

| 操作 | キー |
|---|---|
| 決定 / ゲーム開始 | `Space` / `Enter` |
| 難易度選択 | `←` `→` / `↑` `↓` / `WASD` |
| 移動 | 矢印キー / `WASD` |
| ショット | `Space` / `Z` |
| ボム | `X` |
| ポーズ / 再開 | `P` / `Enter` |
| ミュート切り替え | `M` |
| タイトルへ戻る | `Esc` |
| ステージクリア後に次ステージへ | `Space` / `Enter` |
| ゲームオーバー後リトライ | `Space` |
| ゲームオーバー後タイトルへ戻る | `Enter` |

マウスやタッチ操作にも最低限対応しています。画面内を押している間、自機がポインタ方向へ移動し、ショットも発射します。

## ゲーム内容

- 画面下部の自機を操作して、上から来る敵機や地上兵器を撃破します。
- 敵弾や敵本体に当たるとミスになり、残機が減ります。
- 残機が0になるとゲームオーバーです。
- `P` アイテムを取るとショットが強化されます。
- `BOMB` アイテムを取るとボム回数が増えます。
- 全3ステージ構成で、各ステージ終盤にボスが出現します。
- ステージ1・2のボスを撃破するとステージクリア画面になり、`Space` / `Enter` で次ステージへ進みます。
- ステージ3のボスを撃破するとオールクリアです。
- ハイスコアはブラウザの `localStorage` に保存されます。

## ステージ構成

| ステージ | 名前 | 特徴 |
|---|---|---|
| 1 | `COASTAL BASE` | 海岸沿いの基地。基本的な敵編隊と地上兵器が中心です。 |
| 2 | `FOREST FORTRESS` | 森林要塞。砲台や中型機が増え、敵の耐久と弾幕が上がります。 |
| 3 | `FINAL RUNWAY` | 最終滑走路。敵密度、地上兵器、ボス弾幕がもっとも激しくなります。 |

## 難易度

タイトル画面から開始すると、難易度選択画面に移ります。

- `EASY`: 敵弾が遅めでアイテムが出やすい
- `NORMAL`: 標準バランス
- `HARD`: 敵弾が速く、敵の耐久と出現数が増える

## サウンド

- BGMと効果音はWeb Audio APIでリアルタイム合成しています。
- ステージごとに異なるチップチューン風BGMが流れます。
- ボス出現時はボス専用BGMへ切り替わります。
- ショット、敵弾、爆発、ボム、アイテム取得、被弾、ステージクリア、ゲームオーバーに専用効果音があります。
- ブラウザの仕様上、音はゲーム開始などのユーザー操作後に鳴り始めます。
- 音を止めたい場合は `M` キーでミュートを切り替えられます。

## サーバーの停止

起動中のターミナルで `Ctrl + C` を押すと停止できます。

別ウィンドウで起動してプロセスIDが分かっている場合は、PowerShellで停止できます。

```powershell
Stop-Process -Id <PID>
```

## トラブルシューティング

- 画面が真っ黒、または素材が読み込まれない場合は、`index.html` を直接開かず `node serve.js` で起動してください。
- `node` コマンドが見つからない場合は、Node.js をインストールしてください。
- `4173` ポートが使用中の場合は、`node serve.js 4174` のように別ポートを指定してください。
- 音が鳴らない場合は、一度ゲーム画面をクリックしてから `Space` / `Enter` で開始してください。
